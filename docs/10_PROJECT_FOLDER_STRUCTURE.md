## Rules

- UI code stays inside `apps/web`.
- API/domain code stays inside `apps/api`.
- Shared types are not duplicated.
- Engine adapters cannot directly manipulate UI state.
- Database access stays inside repository/infrastructure layers.
- Artifact paths must be generated by the artifact service.
