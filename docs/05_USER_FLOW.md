# User Flow

## Main navigation

```text
Dashboard
Projects
  ├── Applications
  ├── Environments
  ├── Test Cases
  ├── Test Suites
  ├── Test Plans
  ├── Test Runs
  └── Reports

Engines
  ├── Web
  ├── API
  ├── Mobile
  ├── Performance
  └── Quality

Settings
  ├── General
  ├── Browsers
  ├── Artifact Storage
  └── AI
```

## Test creation flow

```text
New Test Case
 ↓
Choose type
 ↓
Choose engine
 ↓
Configure steps
 ↓
Configure assertions
 ↓
Add data
 ↓
Select environment
 ↓
Validate
 ↓
Save
```

## Execution flow

```text
Select Test/Suite
 ↓
Run
 ↓
Choose environment
 ↓
Choose browser/device
 ↓
Review variables
 ↓
Start
 ↓
Execution screen
 ↓
Result
```

## Result flow

```text
Run summary
 ↓
Passed / Failed / Skipped
 ↓
Select failed test
 ↓
Step details
 ↓
Error
 ↓
Screenshot / Video / Trace / Logs
 ↓
Re-run
```

## AI-assisted flow

```text
Describe requirement
 ↓
AI generates scenarios
 ↓
User reviews
 ↓
User edits/approves
 ↓
Create test cases
 ↓
Execute
```
